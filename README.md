# 🚀 Pulse

Pulse is a full-stack AI-powered fitness and wellness application that delivers personalized workout plans, meal recommendations, recovery insights, and health tracking. It combines Google Gemini AI with MongoDB to provide intelligent, data-driven fitness assistance.

## ✨ Features

- 🤖 AI-powered workout recommendations
- 🥗 Personalized meal planning
- 💬 AI nutrition & fitness coach
- ❤️ Health and wellness tracking
- 🏋️ Exercise library with progress tracking
- 🔐 Secure JWT authentication
- 📊 Performance analytics dashboard

## 🛠️ Tech Stack

**Frontend**
- React
- TypeScript
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Google Gemini AI

## ⚙️ Getting Started

```bash
git clone https://github.com/r-y-riya/Pulse.git
cd Pulse

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

Create a `backend/.env` file using `.env.example` and add your:

- MongoDB Atlas URI
- Gemini API Key
- JWT Secret

Run the application:

```bash
# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm run dev
```
